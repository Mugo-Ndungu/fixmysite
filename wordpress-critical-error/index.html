Guides: Site down or showing an error

WordPress says "There has been a critical error on this website"?

This message means a plugin, theme or code change crashed WordPress. WordPress usually emails the site's admin address a link to log in using recovery mode, where you can switch off whatever caused it.

1. Look for the recovery email

Check the inbox of the site's admin email for a message titled "Your Site is Experiencing a Technical Issue". It names the plugin or theme at fault and includes a recovery mode link. Use the link to log in, then deactivate that plugin or switch theme.

2. No email? Switch off the plugins

Open your host's File Manager or connect by FTP. Rename the folder wp-content/plugins to plugins-off. If the site comes back, rename it back and switch plugins on one at a time in the dashboard until the error returns. That's your culprit.

3. Check the theme

If switching off plugins didn't help, rename your active theme's folder inside wp-content/themes. WordPress falls back to a default theme (such as Twenty Twenty-Four) if one is installed.

4. Turn on the error log

In wp-config.php, set WP_DEBUG and WP_DEBUG_LOG to true. Reload the site, then read wp-content/debug.log: the last lines name the file that failed. Turn debugging off again when you're done.

5. Check the PHP version

If the error started when your host upgraded PHP, an old plugin or theme may not support the new version. Switch back temporarily in your hosting panel, then update or replace the plugin.
