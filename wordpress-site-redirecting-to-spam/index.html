WordPress site redirecting visitors to spam?

If visitors (often only some of them, or only from Google or phones) are sent to spam or scam pages, the site has been hacked, usually through an outdated plugin, theme or weak password. It needs cleaning, closing the hole, and then asking Google to clear any warning.

1. Confirm it

Many hacks only redirect some visitors, so the owner never sees it. Try opening the site from a Google search result, in a private window, and on a phone using mobile data. Search Console's Security issues report shows whether Google has flagged the site.

2. Take a backup before touching anything

Back up the files and database from your hosting panel. Even an infected backup helps if something goes wrong during the clean-up.

3. Lock the door

  • Change every password: hosting account, WordPress admin users, FTP or SFTP, and the database.
  • In WordPress, go to Users and delete any administrator you don't recognise.
  • Update WordPress, every plugin and every theme. Delete plugins and themes you don't use.

4. Find and remove the malicious code

Run a security scanner plugin such as Wordfence or Sucuri. Common hiding places are the .htaccess file, wp-config.php, the active theme's files, and unfamiliar PHP files in the uploads folder. If you have a clean backup from before the hack, restoring it and then updating everything is often the quickest route.

5. Ask Google to clear the warning

Once the site is clean, open Security issues in Search Console and request a review. Warnings are usually removed within a few days of a successful review.
