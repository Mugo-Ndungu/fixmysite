Website slow to load?

Slow small business sites usually come down to a few things: huge photos, no caching, too many plugins or add-on scripts, and cheap overloaded hosting. Measure first, fix the biggest problem, then measure again.

1. Measure it

Run your homepage through PageSpeed Insights and look at the mobile result. Note the load times and the list of "opportunities". Run it again after each fix to see what actually helped.

2. Shrink the photos

The most common problem: a phone photo of 5 MB or more shown in a 600-pixel box. Resize images to the size they're displayed, and save them as WebP or compressed JPEG. On WordPress, an image optimisation plugin can do this for existing images.

3. Turn on caching

Caching serves ready-made pages instead of building each one from scratch. Many hosts include it; on WordPress, use the caching plugin your host recommends (for example LiteSpeed Cache on LiteSpeed servers).

4. Cut plugins and add-on scripts

Every chat widget, tracking pixel, slider and social feed adds weight. Remove the ones nobody uses, and delete inactive WordPress plugins.

5. Check the hosting and PHP version

If the server itself takes over a second to respond, the hosting plan is the bottleneck. Updating to a current PHP version in your hosting panel is a free speed boost for WordPress sites.
