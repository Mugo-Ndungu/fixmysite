GoDaddy website showing "Not secure"?

On GoDaddy the cause depends on what you use. A GoDaddy Website Builder site gets its certificate automatically once the domain points to it correctly. A GoDaddy hosting plan needs a certificate set up on the account, and some plans don't include one.

1. Work out what you have

In your GoDaddy account, open My Products. You'll see whether you have Website Builder (Websites + Marketing), web hosting such as cPanel, or only a domain with the website hosted somewhere else.

2. Website Builder sites

The certificate is issued automatically, but only when your domain points to the builder. If you still see a warning, check the domain's DNS settings: an old record pointing to previous hosting is the usual culprit. Fix the records, then allow a few hours.

3. GoDaddy hosting (cPanel)

Look for an SSL Certificates section in your account. If there's a certificate, check its status: "pending" usually means the domain isn't pointing to the hosting yet, and "expired" needs renewing. If your plan doesn't include one, you can buy one from GoDaddy or use a free certificate where your plan supports it.

4. Domain at GoDaddy, website elsewhere

The certificate comes from wherever the website is hosted, not from GoDaddy. Set it up with that host, and make sure GoDaddy's DNS records point to it.

5. Cover both addresses and force https

Make sure both yourbusiness.com and www.yourbusiness.com work with the padlock, and that plain http redirects to https. See the general "Not secure" guide for more.
