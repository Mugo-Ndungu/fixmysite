Locked out of your WordPress admin?

Start with the password reset link. If the reset email never arrives, you can reset the password from your hosting account instead. Security plugin lockouts and login loops can be cleared from the hosting side too.

1. Use "Lost your password?"

Go to yourbusiness.com/wp-login.php and click Lost your password?. Enter your username or email. Check spam if the email doesn't arrive within a few minutes.

2. Reset email never arrives

Your site may not be able to send email at all (see the contact form guide). Reset the password from your hosting account instead:

  • Many hosts have a WordPress manager with a "change admin password" or "log in to WordPress" button.
  • Otherwise open phpMyAdmin, find the wp_users table (the prefix may differ), edit your user, and set user_pass to a new password using the MD5 function. WordPress upgrades it to a stronger hash when you log in.

3. Locked out by a security plugin

Too many failed attempts can block you. In File Manager or FTP, rename the security plugin's folder inside wp-content/plugins (for example wordfence), log in, rename it back and remove the block in its settings.

4. Login page keeps reloading

Clear your browser's cookies for the site, or try a private window. If it still loops, check that the siteurl and home values in the wp_options table both match your real address, including https and www.

5. Once you're in

Use a strong, unique password, remove admin accounts nobody uses, and add a second administrator you control, so one lost password can't lock the business out again.
