Guides: Site down or showing an error

Website showing "500 Internal Server Error"?

A 500 error means the server hit a problem it couldn't explain to the browser. On small business sites it's usually a recent change: a plugin or theme update, a broken .htaccess file, PHP running out of memory, or the host changing the PHP version.

1. Think about what changed

Did anything update or change in the last day or two? A plugin, theme, WordPress itself, or a setting at your host? The most recent change is the most likely cause.

2. Read the error log

Your hosting control panel has an Errors or Error log section. The newest lines usually name the file or plugin that failed, which saves a lot of guessing.

3. WordPress: switch off the plugins

Using your host's File Manager or FTP, rename the folder wp-content/plugins to plugins-off. If the site comes back, a plugin was the cause. Rename the folder back, then switch plugins on one at a time in the dashboard until the error returns.

4. Check the .htaccess file

Rename .htaccess in your site's main folder to .htaccess-old. If the site loads, the file was broken. In WordPress, go to Settings, then Permalinks, and click Save to create a fresh one.

5. Memory and PHP version

If the log mentions "memory exhausted", raise the PHP memory limit in your hosting panel. If the error started when your host upgraded PHP, switch back to the previous version temporarily, then update the plugin or theme that can't cope with the new one.

6. Still broken?

Contact your host's support with the time it started and the error log lines. Server-level problems are theirs to fix.
